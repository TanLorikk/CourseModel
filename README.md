Тестовое задание для кандидатов.

Инструкция по запуску:

1. Установите Java 17+ и Maven
2. Выполните `mvn spring-boot:run`
3. Перейдите в `http://localhost:8080/students`, `.../professors` и т.д.
4. Для отчёта: `http://localhost:8080/report/professors`
